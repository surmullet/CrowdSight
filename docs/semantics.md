# CrowdSight Measurement Semantics & Invariants

## 1. Core Definition of the Reported Count

Every count metric produced by CrowdSight carries a single, truthful meaning:

> **"Số người nhìn thấy được, do mô hình phát hiện, trong vùng được quan sát."**  
> *(Visible persons detected by the model within the observed zone).*

### 1.1 Prohibited Interpretations
The reported count is strictly an observational detection count:
- Tuyệt đối không coi là sức chứa (Capacity / Venue limit).
- Tuyệt đối không coi là attendance hay lượng người tham dự (Turnstile count).
- Tuyệt đối không coi là độ đông (Crowd level / Congestion tier).
- Tuyệt đối không coi là mức an toàn hay mức nguy hiểm (Safety / Hazard rating).
- Tuyệt đối không coi là thời gian chờ (Queue wait time / Dwell time).

No software component, API endpoint, UI view, or data export may use these terms to characterize the count metric.

## 2. Invariant: Missing Data is NOT Zero

A fundamental design requirement of CrowdSight is the complete separation between observing zero people and having an absence of valid measurement data:

$$\text{Missing Data} \neq 0$$

### 2.1 The Four Quality States
| State | Observation Condition | Count Semantics | UI Representation |
| :--- | :--- | :--- | :--- |
| **VALID** | Frame decoded cleanly; all configured zones fully visible. | `count >= 0` (including affirmative 0). | Clear number or *"0 người được nhìn thấy — vùng đã quan sát đầy đủ"*. |
| **PARTIAL** | Frame valid, but only a subset of zones is fully observable. | Only fully observed zones report counts. Remaining zones are unobserved. | Count for observed zones; **amber diagonal hatching** for unobserved zones. Never 0! |
| **UNKNOWN** | Corrupted frame, blank frame (`FRAME_BLANK`), frozen camera, or unobservable scene. | `count = null`. No detections plotted. | Dot stipple texture; *"Không có số liệu đáng tin cậy ở khung hình này"* + reason code. |
| **STALE** | Temporal gap between requested playback time and observation exceeds limit. | `count = null`. Outdated evidence. | Grayed out, blurred, no count plotted. |

### 2.2 Invariant Enforcement Across the Stack
1. **Domain**: Pure functions in `aggregate_frame()` return `visible_count = None` whenever a zone is not fully observed.
2. **Database**: Table CHECK constraint `ck_zone_result_visible_count_availability` rejects any record where `visible_count IS NOT NULL` if availability is not `'COUNTED'`.
3. **API Contracts**: OpenAPI schemas strictly define `visible_count` as nullable integer with discriminated `availability` status.
4. **Frontend**: Discriminated TypeScript union `ZoneReading = Counted | NotFullyObserved | Unknown | Stale` forces compiler errors if any unobserved state attempts to render a numeric count.
5. **Timeline Charts**: SVG sparklines introduce **physical line breaks (gaps)** for null intervals instead of connecting across unobserved frames or dropping to zero.

## 3. Raw Detector Score vs Calibrated Probability

- The confidence values returned by the detector are **raw model scores** in $[0.0, 1.0]$.
- They represent uncalibrated activations, not true statistical probabilities.
- **Rules**:
  - Never format scores with a percentage sign (`%`).
  - Never label scores as *"độ tin cậy"* or *"mức độ chính xác"*.
  - Hidden by default in the operator review UI. If displayed, labeled strictly as *"Điểm thô của mô hình (chưa hiệu chuẩn)"*.

---

## 4. Relative Image-Space Heat Map (`IMAGE_SPACE`)

- Heat maps are generated by Gaussian splatting of bottom-centre detection anchors on the 2D camera image plane.
- Normalization is relative to the session or time window maximum (`SESSION_MAX` / `WINDOW_MAX`).
- **Rules**:
  - Strictly labeled as **"Tương đối trong khung hình"** (Relative within frame).
  - Không phải bản đồ địa lý (Never referred to as a geographic map).
  - Never interpreted as physical density per square metre.

---

## 5. Metric Density Status

- Metric density requires rigorous ground camera calibration, homography matrix verification, and formal on-site approval.
- Until independent field validation is completed in Vietnam:
  - `density_people_per_m2 = null`
  - `density_status = "UNAVAILABLE_NO_CALIBRATION"`
- Estimation of people per square metre without approved calibration is strictly forbidden.

---

## 6. Fail-Closed Governance

- Model applicability status is locked to `EXPERIMENTAL_NO_APPROVAL`.
- Automated operational alerts are completely disabled:
  - `operational_alerts_allowed = false`
  - No threshold alerts, no notification dispatch channels, and no UI controls to enable them.
