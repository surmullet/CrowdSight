# Demo operations

The first milestone is recorded-video analysis on a local development machine. Before a demo:

- Confirm source video permission, model use/redistribution terms, and who can access the machine and outputs.
- Use an approved demo clip and configuration; label the interface as replay/demo where appropriate.
- Confirm site zones and thresholds are examples unless approved by the responsible site owner.
- Show model/config version, data quality state, and calibration availability alongside results.
- Delete uploaded footage and generated outputs according to the agreed pilot retention policy.
- Do not use the demo as an emergency dispatch or safety control system.

The team must document actual setup/run commands once the runnable MVP exists; none are claimed by this starter repository.
