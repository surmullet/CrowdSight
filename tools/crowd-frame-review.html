CrowdSight frame review

Offline, prediction-free box annotation for a locked evaluation sample. The page processes selected files in this browser tab; it has no upload or network function.

1. Load the locked manifest and source video

For the current candidate, select mixkit-busy-intersection-test-v1.manifest.json and the original busy-intersection-fullhd.mp4. Video hash, dimensions, duration, and frame rate are checked against the manifest before annotation.

Load a manifest to begin.

2. Review every selected frame

Drag to draw a tight box around each visible person. Click a box to select it; mark unresolved plausible people uncertain. Include identifiable partially visible people. Do not label shadows, infer fully hidden people, or use model predictions. Complete a genuinely empty frame with zero boxes.

Review policy and data handling

These are manual reference labels. Pseudo-labels from SAM or another model must be reviewed and corrected before export. A complete frame means every visible person in the whole frame has been reviewed; an empty box list means a reviewed zero-person frame. Use pixel bbox_xyxy coordinates in original image dimensions. Flag unresolved regions as uncertain rather than guessing. Labels are autosaved in this browser's local storage and are not uploaded. Export and store them only in the approved private dataset location.

The current manifest records data permission as pending. Label review can proceed, but do not run held-out inference or describe results as held out until the data owner completes the permission review and independence evidence is reviewed.
